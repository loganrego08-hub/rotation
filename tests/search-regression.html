Search regression: before and after

Runs real queries against live MusicBrainz (about 1 request per second, so this takes under a minute) and asserts the expected album is first. Before = MusicBrainz's own order with the old query. After = api/search.js (loaded and run here) + lib.js ranking. Results are live, so a failure can also mean MusicBrainz data changed; the deterministic version is tests/index.html. Rotation ratings and Billboard signals are not used here (they need the live site), so real results can only be better.
